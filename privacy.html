隐私权政策

深圳天气重视您的隐私权。本应用不会收集、存储或传输任何个人用户数据。

我们收集什么

  • 视频数据：本应用直接加载深圳市气象局提供的公开气象监控视频，不对视频进行任何形式的存储或转发。
  • 设备信息：为实现视频播放，应用可能需要获取基本的设备信息（如屏幕尺寸）以优化播放体验，但不会收集可用于识别您身份的信息。

我们不做什么

  • 我们不会收集您的姓名、电子邮件地址、电话号码等个人身份信息。
  • 我们不会使用 Cookie 或其他追踪技术。
  • 我们不会将任何用户数据分享给第三方。
  • 我们不会显示任何广告。

第三方服务

本应用使用以下第三方服务：

  • 深圳市气象局：提供气象监控视频内容。视频来源由深圳市气象局管理。
  • GitHub Pages：托管本应用。

联系我们

如对本隐私权政策有任何疑问，请通过 GitHub 仓库与我们联系。
